# 默认目标分流

默认分流以用户提供的 `aoxi888.yaml` 为准。只导入目标匹配规则和分组，不包含订阅、节点、密码或 YAML 中的 DNS 设置。

匹配顺序：

1. 116 条手工域名拦截规则（前置自定义分流，拒绝）。
2. 🤖 AI平台。
3. 🛑 全球拦截。
4. 📲 社交聊天。
5. 💻 开发平台。
6. Ⓜ️ 微软苹果。
7. 🎥 国外媒体。
8. 🎯 全球直连。
9. 🐟 漏网之鱼（真正的兜底，默认代理）。

前五个代理类别默认选择可用的第一个节点组；全球直连默认直连，全球拦截默认拒绝。节点组仍由「节点管理」维护。

规则来源：[aoxijy/guize 发布规则](https://github.com/aoxijy/guize/releases/tag/mrs-latest)。使用 `releases/latest/download/<分类>-domain.srs` 和 `<分类>-ipcidr.srs`，拦截类只有域名文件，共 13 份二进制规则。

13 份 SRS 快照随面板服务端一起发布，首次部署可以离线使用；清单 `panel/server/defaults/rule-lists.json` 记录来源、条数和 SHA256。后续按现有 24 小时刷新策略更新，下载失败沿用本地文件。IP 规则只参与流量路由，不进入 DNS 匹配。在线更新使用 sing-box 解码校验，再沿用现有域名/IP 分离存储流程。

全新安装直接使用上述默认分流。升级时，只有完全未改动的 v0.1.186 默认分流会自动替换，原档案保存在数据库键 `jbox/profile-before-aoxi-routing-v1`；自定义过的分流保留，避免覆盖已有设置。应用分流变更仍需通过面板保存并部署内核配置。
